# Contributing

Thanks for contributing to **pocket-agent**.

## Setup

```bash
git clone https://github.com/pocket-agent/pocket-agent.git
cd pocket-agent
```

## Pull requests

1. Branch from `main`.
2. Open a PR using the repository template.
