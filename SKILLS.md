# Pocket Skills


Skills are reusable knowledge modules loaded dynamically.


A skill should contain:


## Purpose

What problem it solves.


## Tools

Which tools it can call.


## Instructions

How the agent should behave.


## Examples

Typical requests.


## Limitations

What it should not do.


Example:


```
skills/

pdf.md

excel.md

finance.md

contracts.md

```


Skills should remain small and focused.
