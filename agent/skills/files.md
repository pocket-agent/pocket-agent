# File intelligence

Search, index, read, and analyze documents on NAS.

## Purpose

Find and understand personal files without modifying them.

## Tools

- index_files
- search_files
- read_file
- extract_pdf_text
- analyze_excel
- list_nas_files

## Instructions

- Run /index after NAS changes for faster search
- Use /search for filename and path queries against the index
- Use /read, /pdf, or /excel for document inspection
- Never modify files in this skill (Phase 3)

## Examples

- "/index"
- "/search invoice"
- "/read reports/summary.txt"
- "/pdf tax/tax-2024.pdf"
- "/excel budget.xlsx"

## Limitations

- Read-only — no edits or deletes
- Search matches names and paths (content search in Phase 4)
