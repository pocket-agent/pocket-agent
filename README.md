# pocket-agent

A lightweight autonomous agent — minimal footprint, runs locally, and easy to extend.

This repository was initialized from the [@open-templates/github-repo-template](https://github.com/open-templates/github-repo-template). Community docs, Dependabot, CODEOWNERS, and GitHub issue/PR scaffolding are in place.

2. Read [INSTRUCTIONS.md](INSTRUCTIONS.md) for maintainer and agent workflows.
3. Add your agent stack (runtime, dependencies, CI) as the project grows.
